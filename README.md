# Awesome Stickman Venture

A fast-paced 2D platformer made in Godot Engine.

---

## 🎮️ About

**Awesome Stickman Venture** is still in pre-alpha, built solo. I would greatly appreciate a helping hand from y'all. 💜

## 🛡️ Security

**Awesome Stickman Venture** is an open-source project, and makes no web requests (unless you count the URIs).

### Notes on running the game:

- On **Windows**, the SmartScreen module might complain about running the executable since it is not signed (at least for now). To fix this:
  - Run the executable.
  - Click "More info", then "Run anyway".

- On **Linux**, the executable may not download with the executable flag. To fix this:
  - Open the terminal.
  - Run `chmod +x /path/to/asv-lin.x86_64`
